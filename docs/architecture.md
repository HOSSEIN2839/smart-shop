# معماری سیستم واسط (Gateway) — دستیار خرید هوشمند

اصل اصلی: **مرورگر و هوش مصنوعی هرگز مستقیم با هم ارتباط ندارند.** همه پیام‌ها از «سیستم واسط» خودمان می‌گذرند.

```
مرورگر کاربر (index.php + chat.js)
   │  POST /api/session.php  ← گفتگوی جدید   |  POST /api/chat.php  ← پیام (فقط فیلد message)
   ▼
[۱] لایه دریافت پیام (app/Http)         Request, ChatController, SessionController
   │  Session + توکن CSRF، فقط POST، بدنه JSON حداکثر ۸KB
   ▼
[۲] سیستم واسط ما (app/Gateway)         ConversationGateway
   │  ConversationStore  ← گفتگوی همین کاربر در MySQL (conversations, messages)
   │  RateLimiter        ← سقف پیام در دقیقه (گفتگو و IP)
   │  InputGuard         ← طول، کاراکتر پنهان، الگوهای تزریق پرامپت
   ▼
[۳] لایه پرامپت (app/Prompt + prompts/) PromptGenerator
   │  System Prompt کامل (اهداف و ممنوعیت‌ها) + تاریخچه از دیتابیس + پیام کاربر داخل <user_message> + یادآوری قوانین
   ▼
[۴] لایه هوش مصنوعی (app/Ai)            OpenAiCompatibleClient (کلید فقط اینجا) / MockAiClient
   │  ← حلقه ابزارها: ToolRegistry (search_products, compare_products) فقط‌خواندنی از MySQL
   ▼
سرویس هوش مصنوعی (API بیرونی)

برگشت: OutputGuard (canary، کلید، لینک/HTML) ← ساخت کارت‌ها از دیتابیس ← ذخیره جواب ← JSON به مرورگر
```

## هر کاربر یک گفتگوی جدید
- `POST /api/session.php` یک ردیف در `conversations` با شناسه تصادفی ۳۲ حرفی می‌سازد و فقط در **Session سرور** نگه می‌دارد.
- مرورگر شناسه گفتگو را نمی‌بیند و نمی‌فرستد؛ نمی‌تواند به گفتگوی دیگران وصل شود.
- تاریخچه فقط از دیتابیس خوانده می‌شود؛ مرورگر نمی‌تواند پیام جعلی با نقش `system` یا `assistant` تزریق کند.
- دکمه «گفتگوی جدید» دوباره `session.php` را صدا می‌زند.

## پرامپت اولیه و Prompt Generator
- `prompts/system_prompt.fa.txt`: هدف‌ها، قانون‌های کار با محصول، ممنوعیت‌ها، قوانین امنیتی و کد محرمانه `{{CANARY}}`.
- `PromptGenerator::build()` هر بار پیام نهایی را می‌سازد؛ پیام خام کاربر هیچ‌وقت مستقیم به مدل نمی‌رود.
- اگر کد canary در جواب مدل دیده شود، یعنی پرامپت لو رفته و جواب مسدود می‌شود.

## لایه‌های دفاعی
۱) InputGuard (ورودی) ← ۲) System Prompt و جداسازی با تگ ← ۳) Allowlist ابزارها و فقط‌خواندنی بودن ← ۴) OutputGuard (خروجی) ← ۵) قیمت/عکس/لینک همیشه از دیتابیس ← ۶) کاربر دیتابیس با کمترین دسترسی ← ۷) rate limit و سقف پیام.

## بدون دامنه
سایت با `http://IP-سرور` باز می‌شود. کلید هوش مصنوعی فقط روی سرور است و هیچ‌وقت به مرورگر نمی‌رسد. چون HTTPS نداریم، متن چت بین مرورگر و سرور رمزنگاری نمی‌شود؛ در این پروژه ورود کاربر و داده شخصی نداریم. (گواهی HTTPS برای IP اختیاری است و در تسک T076 توضیح داده شده.)
